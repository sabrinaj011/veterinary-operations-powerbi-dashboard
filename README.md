# Veterinary Operations Analytics

## Overview

This project demonstrates the end-to-end analytics workflow using Excel and Power BI to clean, transform, model, and visualize veterinary clinic operational data.

## Business Objective

Analyze veterinary clinic performance, revenue trends, patient activity, and treatment data to support operational decision-making.

## Tools Used

- Microsoft Excel
- Power Query
- Power BI
- DAX

## Skills Demonstrated

### Excel

- Data Cleaning
- Data Validation
- XLOOKUP
- Formula Development
- Dataset Preparation

### Power Query

- Data Transformation
- Data Type Management
- Data Standardization
- Query Development

### Power BI

- Data Modeling
- Star Schema Design
- Relationship Management
- Dashboard Development
- KPI Reporting

### DAX

- Total Revenue
- Average Revenue per Visit
- Visit Counts
- Performance Metrics

## Dashboard Features

- Revenue Trends
- Visits by Species
- Clinic Performance
- Treatment Analysis
- Refund Activity

## Project Workflow

Raw Data → Excel Cleaning → Power Query Transformation → Power BI Modeling → Dashboard Reporting
